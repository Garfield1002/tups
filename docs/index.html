tups

= bwrap + pasta + Nix

Ultra-micro containers for coding agents. Box an agent's mistakes in — and move its session between machines.

# one command — no image, no root, ~10 ms to start
tup run web -- cargo test
tup up web
tup move web user@host

Tiny

Inside the box

Two tups on one host — each with its own filesystem, network and process tree. They share a read-only /nix/store, reach the network only through pasta, and the git remote only through the host gatekeeper, which holds the keys.

Why not just Docker?

Docker builds images, which are great for shipping software and isolating hostile tenants. We believe coding agents aren't malicious — just clumsy — so tups trades some security for speed.
